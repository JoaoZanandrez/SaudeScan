Sobre o Saúde Scan

Informação para cuidar melhor.

O que é o Saúde Scan?

O Saúde Scan é um aplicativo desenvolvido para oferecer informações educativas a partir da análise de imagens de lesões na pele.

A proposta é ajudar o usuário a compreender melhor algumas características visuais observadas e encontrar orientações gerais de cuidado.

Como funciona?

01

Envie uma imagem

Tire uma foto ou escolha uma imagem da lesão para iniciar a análise.

02

Análise da imagem

O sistema observa características visuais presentes na imagem.

03

Veja as informações

O resultado apresenta características observadas, possibilidades relacionadas e orientações gerais.

Tecnologias

HTML CSS JavaScript C# ASP.NET Core PostgreSQL API de IA Capacitor

Importante

O Saúde Scan possui finalidade educativa e informativa. A análise de uma imagem não é suficiente para confirmar um diagnóstico.

As informações apresentadas não substituem uma avaliação realizada por um profissional de saúde.

Em caso de dúvida, preocupação ou presença de sinais de alerta, procure atendimento profissional.

Projeto acadêmico

O Saúde Scan foi desenvolvido como projeto acadêmico, com o objetivo de auxiliar no acompanhamento de feridas pós-operatorias, identificando precocemente sinais de complicações por meio de registros de imagens, orientando a busca por avaliação profissional e construindo para um cuidado mais seguro e prevenção de complicações.
